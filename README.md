# Book Wise 📘

### Book Wise é uma aplicação web de avaliação e gerenciamento de leituras. 

### Os usuários podem:

- Visualizar livros existentes no projeto
- Visualizar avaliações de livros
- Visualizar o próprio perfil
- Visualizar perfil de outros usuários
- Buscar livros pelo nome ou autor
- Avaliar livros, com descrição e nota de 1 a 5, caso esteja logado
